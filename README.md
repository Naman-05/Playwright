# Playwright

A hands-on JavaScript learning repository built around core concepts, fundamentals, literals, and operators. This project is structured chapter-by-chapter to make it easy to follow JavaScript basics through small, focused exercises and examples.

## Overview

This repository focuses on learning and practicing:

- JavaScript syntax and fundamentals
- Keywords and identifier rules
- Literals and values
- Arithmetic, assignment, comparison, and logical operators
- Practical examples that reinforce understanding

## Chapter-wise breakdown

- `01_chapter_JS_Basics/` — Introductory JavaScript examples covering the basics, output, and simple math operations.
- `02_chapter_JS_Keywrods_Identifiers/` — Understanding JavaScript engines, `let`, keywords, identifier rules, comments, and quick logic-based tasks.
- `03_chapter_JS_Literals/` — Practice with JavaScript literal values including numbers, `null`, `undefined`, and special literal scenarios.
- `04_chapter_JS_Operators/` — Exercises focused on arithmetic, assignment, comparison, logical operators, and confusing JavaScript comparisons.
